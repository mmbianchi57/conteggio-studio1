# Conteggio studio – VISIO Clinica Oculistica Varese

Programma per il conteggio delle prestazioni dello studio: ripartizione medico/studio, quote fisse (visite pediatriche), ortottisti pagati a ore, resoconto mensile per medico (PDF, email, CSV), totali del centro per mese o per intervallo di date, backup automatici in una cartella.

## Come si usa
È un unico file: `index.html`. Si apre con Chrome o Edge, senza installare nulla.

I dati (prestazioni, ore, impostazioni) restano nel browser del computer su cui si usa e nella cartella di backup scelta: **non sono in questo repository**.

## Scaricare il programma
Vai su **Releases** (a destra) e scarica `Conteggio_studio.html` dall'ultima versione.
